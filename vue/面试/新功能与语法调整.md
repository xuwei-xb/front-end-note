### 新功能与语法调整
1. Fragment 支持：Vue 3 允许组件包含多个根节点，无需额外包裹元素
2. Teleport 与 Suspense：
    - Teleport 可将组件渲染到 DOM 的任意位置（如全局弹窗）。
    - Suspense 简化异步组件加载状态的处理
3. 生命周期钩子重命名：beforeDestroy 和 destroyed 改为 beforeUnmount 和 unmounted
4. 事件总线：
    
    | 特性                | Vue 2 事件总线（EventBus）       | mitt（Vue 3 推荐）               |
    |---------------------|----------------------------------|----------------------------------|
    | **API 设计**        | 依赖 Vue 实例的 `$emit`、`$on`   | 独立库（无框架耦合），提供 `emit`、`on`、`off` 方法 |
    | **作用域**          | 全局或局部 Vue 实例              | 独立实例，可创建多个事件中心（支持模块化隔离）        |
    | **TypeScript 支持** | 需手动扩展类型声明               | 原生支持泛型，提供完整类型定义（如 `Mitt<Events>`）  |
    | **内存管理**        | 需手动调用 `$off` 防止内存泄漏   | 支持批量移除（`off('*')`）或命名空间隔离             |
    | **体积**            | 内置于 Vue 运行时                | 仅 200B 轻量库（Tree-shaking 友好）                |
    | **跨框架兼容性**    | 仅限 Vue 生态                    | 支持任意框架（React、Vue 等）                       |
