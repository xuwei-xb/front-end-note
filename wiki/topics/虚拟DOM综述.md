# 虚拟 DOM 综述

> 类型: topic | 创建: 2026-09-23 | 更新: 2026-09-23
> 来源: [[vue/虚拟DOM]] · [[vue/补充专题]] · [[performance/前端性能优化完全指南]]

## 摘要
虚拟 DOM 是真实 DOM 的轻量化 JS 对象抽象，用于减少框架频繁更新 DOM 时的重排重绘开销，并解耦渲染逻辑以支持跨平台（浏览器 / SSR / React Native）。

## 核心要点
- **为何需要**：框架（Vue/React）频繁更新 DOM 时，直接操作真实 DOM 会触发大量重排重绘；虚拟 DOM 通过 Diff 批量更新降低直接操作次数。
- **优缺点**：优点＝性能批量更新、跨平台、声明式开发；缺点＝首次渲染构建开销、内存占用、极端无 Key 列表 Diff 效率下降。
- **Diff 策略**：同层比较（不跨层，复杂度 O(n) 而非 O(n³)）；Key 用于精准复用/重排；节点类型不同直接替换子树。
- **Vue3 优化 PatchFlag**：编译期给动态节点打静态标记，Diff 只比对标记节点（详见 [[vue/虚拟DOM]] 2.6）。
