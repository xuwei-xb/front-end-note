# Wiki SCHEMA（知识库维护规则）

> 本文件定义 front-end-note 知识库的维护规则。采用「折中路线」：保留现有主题目录作为**笔记层（原始资料）**，在 `wiki/` 下叠加**连接层**。

## 分层结构
- **笔记层**（现有目录 `js/ css/ browser/ ...`）：原始笔记，尽量不改写，只补 `[[双链]]` 与页面头。
- **连接层** `wiki/`：
  - `wiki/index.md` — 统一内容索引
  - `wiki/log.md` — 变更日志
  - `wiki/健康巡检报告.md` — 定期 Lint 结果
  - `wiki/topics/` — 主题综述 / 对比页（编译产物）

## 页面模板（存量笔记补头）
每个笔记顶部建议加：
```
> 类型: note | index | interview | practice
> 创建: YYYY-MM-DD（不详写"不详"）
> 更新: YYYY-MM-DD
> 关联: [[相关页]]
```

## 链接规范
- 跨文件用 `[[相对路径]]`（如 `[[vue/虚拟DOM]]`，不含扩展名）。
- 入口页（`README` / `知识总结` / `Vue完整笔记`）保持相对链接；子文件需**回链**到相关索引，避免单向孤岛。

## 维护纪律
- 新增知识点：判归属目录 → 写笔记 → 在 `wiki/index.md` 登记 → 相关页加 `[[双链]]` → 记 `wiki/log.md`。
- 健康巡检：每月一次，更新 `wiki/健康巡检报告.md`。
- 笔记层原始内容不删不改意；去重 / 合并需先出报告并人工确认。
